# MushroomEatBot
his is a pet project I created while studying for my Data Scientist qualification. The project involves developing an ML model for classifying mushrooms and creating a Telegram bot for user interaction.

The bot allows users to select mushroom characteristics and receive the result: poisonous or edible.
