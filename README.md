# MushroomEatBot
The project involves developing a ML model for classifying mushrooms and creating a Telegram bot for user interaction: https://colab.research.google.com/drive/1TfRNsqtNy7iuaL-DwjlPK6HPo_dpiYt9?usp=sharing

The bot allows users to select mushroom characteristics and receive the result: poisonous mushroom or edible.
